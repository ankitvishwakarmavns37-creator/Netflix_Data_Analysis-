# Project Title
 
Netflix Data Analysis Dashboard (Power BI)

 # Project Description

This project presents an interactive dashboard built using Microsoft Power BI to analyze Netflix content. It helps in understanding trends, genres, and content distribution through visual storytelling.

# Objective
Analyze Netflix dataset using interactive dashboards
Identify trends in movies and TV shows
Provide business insights using visualizations
Enable easy decision-making through reports

# Tools & Technologies Used
Microsoft Power BI
Power Query (Data Cleaning)
DAX (Data Analysis Expressions)
 
# Dashboard Features
Total Movies vs TV Shows
Year-wise Content Growth
Genre-wise Analysis
Country-wise Distribution
Ratings & Duration Analysis
Interactive Filters (Slicers)

# Key Insights
Netflix content increased rapidly after 2015
Movies dominate over TV Shows
Drama and Comedy are the most popular genres
Majority of content comes from the USA

# Dataset
Netflix dataset (public dataset from Kaggle)

 # Conclusion

The dashboard provides clear insights into Netflix’s content strategy and helps understand viewing trends using interactive visualizations.
